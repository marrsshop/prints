Gaz wants to follow the professional client ownership model for all client work:

- Scott owns his own GitHub account and repo
- Gaz is added as a collaborator (full push access, but Scott owns it)
- Scott owns his own Cloudflare account
- Gaz is added as a team member on Cloudflare

This is the intended approach for Scott's site and for future client work generally.

**Why:** Clean separation of ownership, protects both parties, professional standard if Gaz builds this into a business.

**How to apply:** Always set up new client sites under the client's own GitHub/Cloudflare accounts. Never put client work under Gaz's personal accounts long-term. Temporary use of Gaz's account for demos is fine, but migrate before going live.
